Delete Account & Data

Use this page to learn how to request deletion of your PAXELUNE LIFE account and associated data.

Option 1 — Delete from the app

If you can still access PAXELUNE LIFE, open the app's Privacy settings and use the Delete Account & Data action. The in-app feature is described as deleting local device records and synchronized Firebase Cloud Firestore records.

Option 2 — Request deletion by email

If you have uninstalled the app or cannot access it, send a deletion request to our support address. You do not need to reinstall the application to contact us.

This opens your email application with a pre-filled request. The request is not submitted until you send the email.

What happens next?

  • We may need to verify account ownership before processing a request.
  • After verification, the developer must process deletion of applicable account and associated cloud data using the production deletion workflow.
  • Any data retained for a legitimate legal or security reason must be explained to the user.
Developer setup required: this static GitHub Pages form only prepares an email. It does not automatically delete accounts or Firebase records. Before publishing this URL in Google Play Console, ensure that support can receive, verify, and fulfill deletion requests and that the process is documented accurately.
